## 예시 산출물(설교문·성경 본문 뷰어)에 대하여
공개 배포판에서는 **저작권 보호를 위해 예시 설교문(md)과 성경 역본 본문을 담은 HTML 뷰어(html)를 포함하지 않습니다.**
- 임도균 교수 「스토리가 살아있는 설교」의 예시 설교문은 저작물이므로 배포하지 않습니다. 원 예시는 책을 참고하십시오.
- 성경 역본(개역개정·새한글·새번역·공동번역 = 대한성서공회 / ESV = Crossway) 전문을 담은 뷰어도 판권 문제로 제외했습니다. 각 역본은 대한성서공회(bskorea.or.kr)·ESV.org에서 직접 확인·이용하십시오.

각 스킬(특히 `tnt-step01-select`·`tnt-step07-draft`)은 뷰어·프롬프터의 **형식 규격을 본문 안에 자세히 기술**하고 있으므로, 사용자는 자신의 본문·역본으로 산출물을 직접 생성할 수 있습니다.
