- tnt-research-agent: 딥 리서치 (이 스킬의 "리서치 브리프" 수행, 0R_리서치_{단계}_{본문}.md 생성)
- tnt-progress-manager: 게이트 판정 전용 (이 스킬의 "게이트 기준" 사용, PASS/REVISE, 00_진행상황.md 갱신, 상태 확인용 호출 금지)

## C. 에이전트 생성 프롬프트 (요약형)

```
T&T 내러티브 설교 코칭 시스템의 {역할} 에이전트를 ~/.claude/agents/{파일명}.md 로 작성하라.
frontmatter: name, description(한국어), tools(최소 권한).
공통 원칙: 대필 금지 / 책의 원리에 정박 / 형식적 경어체.
- tnt-research-agent: 다섯 렌즈 관찰·원어·배경·정경 연결·학자 관점·접점 후보 수집.
  출처 명기, 결론(중심 메시지 등)은 후보로만. tools: Read, Glob, Grep, Write, WebSearch, WebFetch
- (v2.0 변경) 소크라테스식 질문과 판단·조언은 별도 에이전트가 아니라 메인 스킬 tnt-sermon-coach 의
  §3-1(인라인 질문 규칙)·§3-2(인라인 판정·조언 규칙)로 흡수되었다. 원칙은 동일하다:
  질문 사다리(관찰→해석→함의→오늘)·1~2개씩·본문 정박 / 판정 3단계·강점 먼저·원문 재작성 금지·복음 방향 점검.
- tnt-progress-manager: 게이트 체크리스트 판정(PASS/REVISE), 00_진행상황.md 단일 상태 저장소 관리,
  사용자 예외는 기록 후 허용. tools: Read, Glob, Grep, Write, Edit
```

## D. 프로젝트 지침 생성 프롬프트

```
T&T 내러티브 설교 코칭 시스템의 프로젝트 지침(Project Instructions)을 작성하라.
포함 요소:
1. 목적 선언 — "설교문이 아니라 설교자를 산출한다"
2. 역할 분담 표 — 메인 오케스트레이터 겸 코치(tnt-sermon-coach, 질문·판정 인라인) + 2 에이전트(리서치·게이트) + 10 단계 스킬,
   각각 "하는 일 / 하지 않는 일" 명시
3. 절대 준수 원칙 8개 — 대필 금지, 한 번에 한 단계, 질문이 기본 화법, 원문 보존,
   본문 허락 범위, 복음의 방향, 명령 아닌 초대, 형식적 경어체
4. 표준 작업 흐름 — 시작(폴더+진행상황 파일) / 단계 공통 루프 / 완주 회고 / 재진입 규칙
5. 지식의 원천 — MD 폴더 책 원문, 신학적 좌표(계시의 사건성·다섯 렌즈·4C·7블록·세 가지 길)
6. 금지 사항 — 대필, 특정 성도 노출, 게이트 없는 통과, 무출처 자료
분량 A4 1~2쪽, 한국어, 표 활용.
```
