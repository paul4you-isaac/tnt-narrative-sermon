# 6단계. 설교의 길을 선택하라 — 코칭 스킬

이 스킬은 T&T 내러티브 설교 코칭 시스템(tnt-sermon-coach)의 6단계 전용 스킬입니다.
4단계에서 중심 메시지 한 문장을 붙들고, 5단계에서 오늘의 청중 얼굴을 떠올렸다면,
6단계의 질문은 하나입니다. "이 본문과 이 청중에게 들어가려면 어느 길이 가장 자연스러운가?"

이 스킬은 설교문을 대신 쓰지 않습니다. 모델도 대신 고르지 않습니다.
설교자가 습관이 아니라 본문과 청중의 필요에 따라 길을 의식적으로 선택하도록 코칭합니다.
같은 본문이라도 길이 달라지면 설교의 속도, 감성의 곡선, 청중이 숨 쉬고 붙잡는 지점이 달라집니다.

## 단계 목표와 사용자 산출물

- 목표: 단순형(One-way) / 대화형(Dialogue D1~D6) / 대지형(Point P1~P5) 중
  이번 본문과 청중에 맞는 모델을 사용자가 의식적으로 선택합니다.
- 선택 기준: 책이 제시하는 4체크포인트.
  ① 본문의 길이와 주된 감성의 곡선 ② 청중의 상태 ③ 설교 시간과 예배 환경 ④ 설교자의 강점 스타일.
- 사용자 산출물: `06_모델선택_{본문}.md` — 선택한 모델 + 선택 이유(사용자 자신의 문장).
- 확정된 모델은 `00_진행상황.md` frontmatter의 `model` 필드에 기록됩니다.
  이 값은 7단계(초안 작성)의 구조 뼈대가 되므로, 게이트 통과 전 반드시 기록을 확인하십시오.

## 진행 프로토콜

공통 루프를 따릅니다.

1. 상태 확인 — 코치가 `00_진행상황.md`를 직접 읽어 5단계 PASS 여부와
   4단계 중심 메시지(central_message)를 확인합니다. 미완료 시 해당 단계로 안내합니다.
2. 리서치 — `tnt-research-agent`에 아래 "리서치 브리프"를 전달하여
   `0R_리서치_{본문}.md`를 생성하게 합니다.
3. 질문 — 코치가(인라인) 아래 "질문 뱅크"에서 1~2개씩 설계하여 던집니다.
   4체크포인트를 한꺼번에 묻지 않고, 하나씩 순서대로 확인합니다. 답을 대신 말하지 않습니다.
4. 판단·조언 — 코치가 아래 "평가 루브릭"으로 사용자의 선택 이유를 직접 심사합니다.
   판정은 충분함 / 거의 됨 / 다시 생각. "다시 생각"이면 3번으로 돌아갑니다.
   코치는 특정 모델을 추천하지 않습니다. 다만 선택 이유가 4체크포인트와
   명백히 상충하면(예: 10분 새벽예배에 대화형 선택) 그 상충을 질문으로 드러냅니다.
5. 저장 — 사용자가 쓴 모델명과 이유 문장을 원문 그대로 `06_모델선택_{본문}.md`에 저장합니다.
   코치가 문장을 다듬거나 재작성하지 않습니다.
6. 게이트 — `tnt-progress-manager`가 아래 "게이트 기준"으로 PASS/REVISE를 판정하고
   `00_진행상황.md`를 갱신합니다(PASS 시 model 필드 기록 포함).

## 세 모델 요약 표

사용자 교육용입니다. 질문에 앞서 이 표를 간단히 보여 주고, 각 모델을 한 줄씩 설명하십시오.

| 구분 | 단순형(One-way) | 대화형(Dialogue) | 대지형(Point) |
|---|---|---|---|
| 흐름 | Today → Text → Today (일직선) | Today ↔ Text 왕복 (D1~D6) | Today 공감 → Text 전체 스토리 → 다리 질문 → 대지 2~3개(Text & Today) → Today 결단 (P1~P5) |
| 주된 청중 반응 | "이해했다" | "느꼈다" | "기억했다" |
| 적합 상황 | 10~15분 짧은 설교, 새벽·수요예배, 심방, 초신자·다음세대, 추모·결혼 등 특별예배 | 25분 이상, 치유·회복·정체성 주제, 감정 곡선이 큰 본문, 집회·수련회 | 제자·리더 훈련, 소그룹 재전달, 시리즈 정리 주간, 교리·윤리 주제 |
| 강점 | 방향이 선명, 중심 메시지 하나를 못 박음 | 몰입·공감 극대화, 복음이 이해가 아니라 경험이 됨 | 이야기의 몰입감과 메시지의 명료함을 동시에 살림, 노트·재전달 용이 |
| 주의점 | 감정의 결이 얕아질 수 있음 | 전환 문장 없이 왕복하면 산만해짐, 구조가 복잡 | 대지로 자르다 이야기가 단절될 위험, 다리 질문(Bridge Question)이 없으면 온도가 식음 |

핵심 원리 한 문장: "본문은 하나, 길은 셋이다. 어느 길을 택하든 본문이 스스로 말하게 하라."

## 설교 분량·시간 안내 (모델 선택 시 함께)

모델을 정할 때 **설교 시간 → 목표 분량**을 함께 잡아 두면, 이후 초안·조립 단계에서 길이가 어긋나지 않습니다. 코치는 설교자가 6단계에서 말한 설교 시간을 근거로 목표 자수를 안내합니다.

- 한국어 강단 낭독 속도는 대략 **분당 300~350자**(호흡·침묵 포함). 기준값 **약 330자/분**.
- 시간별 목표 자수(공백 제외, 대략): **10분 ≈ 3,300자 / 15분 ≈ 5,000자 / 20분 ≈ 6,600자 / 25분 ≈ 8,300자 / 30분 ≈ 9,900자.**
- 모델별 분량 특성: 단순형은 짧게(10~15분)도 완결, 대화형은 왕복이 있어 25분 이상에서 편안(짧으면 왕복 압축), 대지형은 대지 수에 따라 늘어남.
- 이 목표는 6단계 산출물(`06_모델선택`)에 "설교 시간·목표 자수"로 적어 두고, **9단계 조립 후 실제 자수·예상 낭독 시간과 대조**합니다(§tnt-step09-resolve 마무리 파이프라인). 목표는 상한이 아니라 나침반입니다.

## 리서치 브리프

`tnt-research-agent`에 전달할 요청 사양입니다. 산출: `0R_리서치_{본문}.md`.

- 본문의 길이·구조 특성: 절 수, 단락 구분, 플롯(발단–긴장–전환–절정–해결)이
  한 단락 안에 응축되어 있는지 여러 장면에 걸쳐 있는지.
- 본문의 감성 곡선 분석: 인물의 감정이 어떤 흐름(예: 갈망–수치–긴장–만남–회복)으로
  움직이는지, 감정의 오르내림 폭이 큰지 완만한지, 전환(복음의 반전)이 일어나는 절.
- 대지화 가능성 자료: 본문에서 자연스럽게 떠오르는 핵심 전환 장면 목록
  (대지 후보가 아니라 장면 목록으로만 제시).
- 장르·문맥 참고: 앞뒤 문맥, 병행 본문, 본문이 교육적 정리에 적합한 교훈 요소를 포함하는지.
- 금지: 어떤 모델이 적합하다는 추천·암시를 일절 포함하지 않습니다.
  자료는 판단 재료일 뿐, 판단은 설교자의 몫입니다.

## 소크라테스 질문 뱅크

한 번에 1~2개만 사용합니다. 예시는 모두 마가복음 5:25-34(혈루증 여인)입니다.
이 본문은 짧지만 감성 곡선이 크고(12년 고통–손끝–멈춤–"딸아") 교훈 정리도 가능해
세 모델이 모두 성립하는 본문이므로, 예시가 특정 모델을 유도하지 않습니다.

체크포인트 ① 본문의 길이와 감성 곡선
- Q1. 이번 본문의 감정은 어디서 가장 크게 출렁입니까? 그 출렁임을 설교에서
  충분히 타고 가야 합니까, 아니면 한 장면으로 선명히 보여 주면 충분합니까?
  (예: 막 5장에서 여인의 12년, 손끝, 예수님의 멈추심 중 어디가 절정이라고 보십니까?)
- Q2. 이 본문이 청중에게 남겨야 할 것은 한 장면입니까, 한 번의 감정 경험입니까,
  아니면 손에 쥐고 갈 정리된 진리입니까?

체크포인트 ② 청중의 상태
- Q3. 이번 주 청중은 구조에 익숙한 분들입니까, 처음 듣는 분들이 많습니까?
  그 상태가 길 선택에 어떤 영향을 줍니까?
- Q4. 이 설교 후 청중에게 필요한 것은 무엇입니까 — 잘 들리는 것입니까, 잘 남는 것입니까?
  (예: 막 5장을 새가족 예배에서 전할 때와 리더 수련회에서 전할 때 무엇이 달라집니까?)

체크포인트 ③ 설교 시간과 예배 환경
- Q5. 이번 설교의 실제 시간은 몇 분입니까? 그 시간 안에 Today와 Text를
  두 번 이상 깊이 왕복할 여유가 있습니까?
- Q6. 예배 후 소그룹 나눔이나 재전달이 예정되어 있습니까? 있다면 청중이
  들고 나가야 할 것은 무엇입니까?

체크포인트 ④ 설교자의 강점 스타일
- Q7. 목사님의 강점은 논리·구조 정리, 공감·감정선·스토리 전개, 요약·교육적 전달 중
  어디에 가깝다고 보십니까? 이번 선택은 그 강점을 쓰는 선택입니까, 확장하는 선택입니까?
- Q8. 이번에 강점 밖의 길을 택한다면, 그 길의 주의점(감정 결 얕음/산만함/이야기 단절)을
  어떻게 보완하시겠습니까?

습관 점검 질문
- Q9. 최근 다섯 번의 설교에서 어떤 길을 걸으셨습니까? 이번 선택은 그 패턴의 반복입니까,
  본문과 청중이 요구한 결과입니까?
- Q10. 만약 이번 본문을 전혀 다른 청중(예: 막 5장을 새벽예배 10분 / 치유의 밤 30분 /
  리더 수련회) 앞에서 전한다면 길이 달라집니까? 달라진다면 왜, 안 달라진다면 왜입니까?

## 평가 루브릭

코치가 사용자의 "선택 모델 + 이유"를 인라인 심사할 때 사용합니다.
원문을 재작성하지 않고, 판정(충분함/거의 됨/다시 생각)과 짧은 조언만 제시합니다.
특정 모델 추천 금지. 이유의 논리만 심사합니다.

평가 축
1. 4체크포인트 부합성 — 이유가 본문 감성 곡선, 청중 상태, 시간·환경, 강점 중
   최소 2개 이상과 논리적으로 연결되는가. 명백한 상충(예: 12분 설교 + 대화형 왕복 2회 이상,
   재전달 필요한 훈련 자리 + 대지 없는 구조)이 있으면 상충을 질문으로 드러낸다.
2. 이유의 구체성 — "은혜로울 것 같아서" 수준이 아니라 이번 본문의 절·장면과
   이번 청중의 실제 상태를 언급하는가.
3. 습관 여부 자각 — 늘 쓰던 길인지 스스로 점검한 흔적이 있는가.
   습관과 같은 선택이어도 본문·청중 근거가 서 있으면 통과. 습관이라는 이유만으로 탈락시키지 않는다.

흔한 오답 패턴과 조언 포인트
- "저는 원래 대지형이라서요." → 습관 진술만 있고 본문·청중 근거가 없음.
  Q9·Q10으로 회귀. "이번 본문과 청중이 같은 답을 줍니까?"
- "세 개 다 좋아 보여서 섞겠습니다." → 6단계는 한 길을 정하는 단계.
  혼합은 8단계 고도화에서 다룰 일이며, 지금은 기본 골격 하나를 결단하게 한다.
- "청중이 은혜받게 대화형이요." → 막연함. 어느 감정 곡선을, 몇 분 안에,
  어떤 청중과 왕복할 것인지 구체화 요청.
- 시간과 상충하는 선택 — "새벽예배 10분인데 대화형" 등.
  대화형은 최소 두 번 이상의 깊은 왕복이 가능해야(대략 25분 이상) 안정적임을 상기시키고,
  그래도 선택을 유지한다면 그 근거를 묻는다. 최종 결정권은 설교자에게 있다.
- 잘 들리는 것과 잘 남는 것의 혼동 — 몰입(느꼈다)과 기억(기억했다)은 다른 방식으로
  만들어짐을 짚고, 이번 설교의 목표 반응이 무엇인지 되묻는다.

## 게이트 기준

`tnt-progress-manager`의 PASS 체크리스트입니다. 하나라도 미충족이면 REVISE.

- [ ] 세 모델 중 하나가 명시적으로 선택되었다(혼합·보류 아님).
- [ ] 선택 이유가 4체크포인트 중 2개 이상과 구체적으로 연결된다.
- [ ] 이유에 이번 본문의 실제 특성(길이·감성 곡선·장면)이 언급된다.

## 흔한 함정과 코칭 포인트

1. 취향이 기준을 이기는 함정 — 강점은 고정된 정체성이 아니라 훈련으로 확장되는 영역입니다.
   한 모델만 고집하는 설교자에게는 "본문과 청중에 따라 길을 바꾸는 훈련"이라는
   책의 관점을 상기시키되, 이번 선택 자체는 존중하십시오.
2. 시간 계산 없는 대화형 — 왕복이 생명인 대화형은 짧은 시간에 쓰면 오히려 산만해집니다.
   실제 설교 분량을 분 단위로 확인하게 하십시오.
3. 이야기를 자르는 대지형 — T&T 대지형은 대지를 위해 이야기를 줄이는 구조가 아니라,
   이야기를 먼저 살려 들려준 뒤 대지가 떠오르게 하는 구조입니다.
   다리 질문(Bridge Question) 없이 "이제 교훈을 말하겠습니다"로 넘어가면 온도가 식습니다.
4. 단순형을 얕은 설교로 오해 — 단순형은 짧지만 얕지 않습니다.
   "이번 주에 분명히 붙들 한 가지는 무엇인가"에 답할 수 있을 때 가장 강력합니다.
5. 선택을 코치에게 미루는 함정 — "뭐가 좋을까요?"라고 물으면 답하지 말고,
   4체크포인트 질문으로 되돌리십시오. 모델 선택은 설교자의 결정입니다.
