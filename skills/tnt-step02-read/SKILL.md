# 2단계. 본문을 정독하라 — 코칭 스킬

## 역할과 위치

이 스킬은 T&T 내러티브 설교 10단계 코칭 시스템의 2단계 지침서입니다. 메인 오케스트레이터 `tnt-sermon-coach`가 이 스킬을 로드하며, 질문(소크라테스 질문 뱅크 사용)과 판정·조언(평가 루브릭 사용)은 코치가 인라인으로 직접 수행합니다. 서브에이전트는 둘입니다: `tnt-research-agent`는 리서치 브리프를 받아 0R 파일을 생성하고, `tnt-progress-manager`는 게이트 판정 시에만 호출됩니다(상태 확인용 호출 금지).

**대필 금지 원칙.** 이 단계의 산출물인 다섯 렌즈 관찰 노트는 반드시 설교자가 직접 채웁니다. 코치는 관찰 결과를 대신 써 주지 않습니다. 리서치 에이전트는 배경·원어·문맥 등 설교자가 스스로 얻기 어려운 자료만 제공하고, "본문에서 무엇이 보이는가"라는 관찰 자체는 질문으로 이끌어 설교자가 발견하게 합니다. 코치(인라인)도 설교자의 문장을 재작성하지 않고 판정과 조언만 합니다.

책의 원리: 본문을 한두 번 읽고 바로 설교를 쓰면 설명 중심 설교가 됩니다. 설교자는 먼저 건축가처럼 도면(설계도)을 들여다보아야 하고, 그다음에야 하나님의 이야기꾼이 될 수 있습니다. 반복이 곧 관찰의 문입니다.

## 단계 목표와 사용자 산출물

- 목표: 반복 읽기·듣기와 다섯 렌즈 관찰로 본문을 정보 목록이 아니라 하나의 이야기 설계도(Story Architecture)로 보게 합니다. 본문이 "움직이는 장면"으로 바뀌는 것이 이 단계의 완성입니다.
- 사용자 산출물: `02_다섯렌즈관찰_{본문}.md` — 다섯 렌즈 관찰 노트. 설교자의 원문 그대로 저장합니다.
- 전제: 1단계 산출물(본문 선별)이 존재해야 합니다. 없으면 1단계로 안내합니다.

## 진행 프로토콜

공통 루프를 따릅니다. ①상태 확인 → ②리서치 → ③질문 → ④판단·조언 → ⑤산출물 저장 → ⑥게이트.

1. **상태 확인** — 코치가 00_진행상황.md와 1단계 산출물을 직접 읽어 선택된 본문을 확인합니다. (`tnt-progress-manager`는 게이트에서만 호출합니다.)
2. **TTS 본문 HTML 생성 (읽기 도구 준비)** — 네 번 읽기 과제를 내기 전에, 아래 「TTS 본문 HTML 생성」 절차로 `02_TTS본문_{본문}.html`을 만들어 설교자에게 건넵니다. 1단계 구문 배열의 **본문만**(앞·뒤 페리코페 제외) 담고, 성우·속도 선택과 밑줄 기능을 제공하여 ①낭독 듣기(④ 듣기 청취)와 ② 걸리는 단어 밑줄 긋기를 이 한 파일에서 하게 합니다.
3. **네 번 읽기 과제 부여** — 질문을 시작하기 전에, 설교자에게 아래 루틴을 실제 과제로 제시하고 수행 후 돌아오게 합니다. 이 과제는 건너뛰지 않습니다. (2번의 HTML을 열어 ①③은 눈으로 읽으며 밑줄, ④는 재생 버튼으로 반복 청취하도록 안내합니다.)
   - ① 소리 내어 빠르게 1~2회 읽기: 흐름을 끊지 않고 읽어 이야기의 리듬과 속도감을 몸으로 익힙니다. 어디서 빨라지고 어디서 멈추는지 감으로 잡습니다.
   - ② 천천히 1~2회 읽기: 마음에 걸리는 단어, 멈추게 하는 문장에 밑줄을 긋습니다. 반복되는 표현, 갑자기 튀어나오는 말, 설명 없이 지나가는 행동에 주목합니다.
   - ③ 표정과 움직임을 상상하며 1회 읽기: 인물들의 표정, 숨, 손짓, 거리감, 시선의 방향을 따라갑니다. 해석을 더하는 것이 아니라 본문이 이미 품고 있는 감정과 몸짓을 발견하는 읽기입니다.
   - ④ 듣기 성경으로 반복 청취: 걷거나 이동하는 시간에 반복해 들어 본문이 몸에 스며들게 합니다.
   - 과제 확인 질문: "읽으면서 밑줄 친 단어나 문장은 무엇이었습니까?" 이 답이 없으면 읽기 과제로 되돌립니다.
4. **리서치** — `tnt-research-agent`에게 아래 리서치 브리프를 전달하여 `0R_리서치_{본문}.md`를 생성하게 합니다. 리서치 결과는 관찰의 재료로만 제공하고, 관찰 문장을 대신 만들지 않습니다.
5. **렌즈별 질문 코칭** — 코치가(인라인) 아래 질문 뱅크에서 렌즈당 1~2개씩 설계하여 배경→인물→플롯→주된 감성→신학적 메시지 순으로 진행합니다. 한 번에 한 렌즈만 다룹니다. 답을 대신 말하지 않습니다.
6. **판단·조언** — 렌즈마다 코치가 평가 루브릭으로 직접 판정합니다(충분함 / 거의 됨 / 다시 생각). "다시 생각"이면 4~5단계로 회귀하되, 같은 렌즈에서 3회를 넘기면 현재 답을 잠정 기록하고 다음 렌즈로 넘어간 뒤 마지막에 재방문합니다.
7. **산출물 저장** — 다섯 렌즈가 모두 "충분함" 또는 "거의 됨"이면, 설교자의 문장을 원문 그대로 아래 파일 형식으로 저장합니다.
8. **게이트** — `tnt-progress-manager`가 게이트 기준으로 PASS/REVISE를 판정하고 00_진행상황.md를 갱신합니다. PASS면 3단계(본문을 재현하라)로 안내합니다.

## TTS 본문 HTML 생성 (2단계 청취·밑줄 도구, 2번 절차 상세)

> ★ **처음부터 짜지 않는다.** `${CLAUDE_PLUGIN_ROOT}/assets/tts-reader.html`를 읽어
> `{{자리표시자}}`만 채워 저장한다. **CSS·JS는 한 글자도 바꾸지 않는다** — 검증된
> 구현체이며, 손대면 절 번호 소실·호흡 줄나눔 소실 같은 기존 버그가 되살아난다.
> 자리표시자 목록·데이터 스키마·검증 절차는 `${CLAUDE_PLUGIN_ROOT}/assets/README.md`.
> `{{TEXT_DATA}}`는 개역개정·새한글 **둘 다** 채운다.
> 아래 서술은 **무엇을 채울지**(이 단계의 내용 판단)를 정한다 — 만드는 방법이 아니다.


2단계의 "네 번 읽기" 중 ④ 듣기 청취와 ② 밑줄 긋기를 한 파일에서 하도록, 코치는 자기완결형(self-contained) HTML 한 개를 만듭니다. 외부 라이브러리·네트워크 없이 브라우저 표준 Web Speech API(SpeechSynthesis)로 동작합니다.

**파일명·저장 위치**: `02_TTS본문_{본문}.html` (프로젝트 폴더 안, 예: `02_TTS본문_막5_25-34.html`)

**본문 내용 규칙**
- 1단계 산출물 `01_본문선별_{본문}.md`의 "본문 텍스트 (구문 배열)"에서 **── 본문 ── 구획만** 가져옵니다. **앞·뒤 페리코페는 제외**합니다.
- 구문 배열의 **들여쓰기 위계와 절 번호를 그대로 보존**합니다(원문 무수정).
- 각 줄(구문 단위)을 개별 요소로 감싸 밑줄 토글과 낭독 하이라이트가 줄 단위로 되게 합니다.
- **절 번호의 위치 — 그 절 첫 줄과 같은 줄에 매답니다(필수)**: 위 규칙대로 각 줄을 블록 요소로 만들면서 절 번호를 그 앞에 두면 **번호만 홀로 한 줄을 차지하고 본문 첫 줄이 다음 줄로 밀립니다.** 반드시 절 번호를 **그 절 첫 줄 요소 안에** 넣고 내어쓰기(`text-indent`, 음수)로 왼쪽에 매달아, 번호와 첫 구문이 **같은 줄**에 오게 합니다. 둘째 줄 이하는 본문 시작 위치에 정렬됩니다. 구현 골자 — 절 컨테이너에 `padding-left`, 첫 줄 요소에 같은 값의 음수 `text-indent`, 번호 span은 그 값과 같은 `width`의 `inline-block`.
  ```
   1  예수께서 여리고로 들어가
      지나가시더라
  ```
- **밑줄이 절 번호에 걸리지 않게 합니다**: 절 번호가 첫 줄 요소 안에 들어가므로, 밑줄을 그 요소에 직접 걸면 번호까지 밑줄이 그어집니다. 줄 안의 **본문 텍스트만 별도 span으로 감싸** 그 span에 밑줄을 적용합니다(예: `.line.mark .text { text-decoration: underline }`).
- **함정 2건(실사용에서 확인됨 — 반드시 지킬 것)**
  1. **번호 span에 `text-indent:0`을 명시합니다.** `text-indent`는 상속되므로 첫 줄에 걸어 둔 음수 값을 번호 span(`inline-block`)이 물려받아 **자기 글자를 상자 밖으로 밀어냅니다.** 그러면 상자는 제자리인데 **숫자만 화면에서 사라집니다.**
  2. **내어쓰기 폭은 `rem`으로 통일합니다.** `em`은 요소별 글꼴 크기 기준이므로, 번호 span의 작은 글꼴에서 `2.6em`은 컨테이너의 `2.6em`과 다른 값이 되어 폭이 어긋납니다.
- **검증법 — 상자가 아니라 글자를 측정합니다.** `getBoundingClientRect()`는 번호 *상자* 좌표를 주므로, 글자가 상자 밖으로 밀려나 보이지 않아도 **통과합니다(위 함정 1의 실제 오진 사례).** `document.createRange()` + `selectNodeContents(번호span)`으로 **글자가 그려진 좌표**를 얻어 ① 글자가 상자 안에 있는지 ② `left > 0`인지 ③ 첫 줄 본문과 같은 줄인지 ④ 번호가 본문 왼쪽인지를 확인하고, 밑줄 적용 시 번호 span의 `text-decoration-line`이 `none`인지도 확인합니다. 가능하면 **스크린샷으로 눈으로도 확인**합니다.

**필수 UI 기능**
1. **성우 선택** — 드롭다운: `민수`, `지안`, `수현`, `유나` (macOS 한국어 음성 페르소나). 페이지 로드 시 `speechSynthesis.getVoices()`에서 `ko-KR` 음성을 찾아 이름에 매칭하고, 매칭 실패 시 사용 가능한 한국어 음성으로 조용히 대체합니다.
2. **음질(내부 처리, UI 없음)** — 음질 선택 버튼은 **노출하지 않습니다.** 성우 매칭 시 **프리미엄/향상(Enhanced·Premium) 음성이 있으면 자동으로 먼저 적용**하고, 없으면 기본 음성을 씁니다. 이 대체·등급 처리는 사용자에게 별도로 표시하지 않습니다(안내 문구·알림 없음).
3. **속도 선택** — `1.0` · `1.25` · `1.5` (SpeechSynthesisUtterance.rate). 기본 1.0.
4. **재생 컨트롤** — 재생 / 일시정지 / 정지. 재생 중인 줄을 배경 하이라이트로 표시(현재 낭독 위치 추적).
5. **밑줄 기능** — 각 줄(또는 드래그 선택 범위)을 클릭/탭하면 밑줄 토글. "밑줄 지우기" 버튼. 밑줄 상태는 `localStorage`에 본문 키로 저장해 새로고침해도 유지. (설교자가 "걸리는 단어·문장"을 표시하는 2단계 핵심 행동을 지원)
6. **마치기 버튼(코치 전달)** — 읽기를 마치면 누릅니다. 눌렀을 때:
   - 밑줄 친 줄들을 **절 번호 + 구문** 형식으로 모아 제출용 텍스트를 만듭니다. 연속 줄(절 번호 없는 구문)은 바로 위의 절 번호를 이어 붙입니다.
   - 머리말 `[2단계 밑줄 제출 — {본문}]`을 붙이고, **자동으로 클립보드에 복사**(`navigator.clipboard`)합니다.
   - 화면에 그 텍스트를 **선택 가능한 상자**로 띄우고 안내합니다: "밑줄 요약이 복사되었습니다. 클로드 대화창에 붙여넣기(⌘/Ctrl+V) 하시면 다섯 렌즈 관찰을 이어갑니다." (클립보드 실패 시 수동 복사 안내)
   - 밑줄이 하나도 없으면 "걸리는 단어·문장에 먼저 밑줄을 그어 주십시오"라고 알립니다.
   - 로컬 file:// HTML은 대화창으로 직접 전송할 수 없으므로, 이 복사→붙여넣기 흐름이 표준 전달 방식입니다.
7. 상단에 본문 표기(예: "마가복음 5:25-34 · 개역개정 · 구문 배열")와 짧은 사용 안내. 음질 관련 표기·안내는 넣지 않습니다.

**마치기 → 코치 인계**: 설교자가 붙여넣은 `[2단계 밑줄 제출 …]` 텍스트를 코치가 받으면, 그 밑줄 목록을 다섯 렌즈 관찰의 출발 재료로 삼습니다. 밑줄 친 지점을 먼저 짚어(배경·주된 감성 렌즈와 자주 연결됨) "이 단어에 왜 걸리셨습니까"류의 질문으로 렌즈 코칭(진행 프로토콜 5번)을 시작합니다. 밑줄을 대신 해석하지 않고, 설교자의 발견을 여는 실마리로만 씁니다.

**기술·품질 요건**
- `<!doctype html>`부터 완결된 단일 .html. CSS·JS 인라인. 외부 요청 0.
- 라이트/다크 모두 읽기 쉬운 명도, 큰 본문 폰트(설교 준비용), 모바일 대응(걸으며 청취 가능).
- 성경 텍스트는 코치가 생성하지 않고 1단계에서 사용자가 붙여넣어 확정된 본문을 그대로 씁니다.
- 낭독 시 절 번호·기호가 어색하게 읽히지 않도록, 화면 표시는 원문 그대로 두되 낭독 텍스트에서는 줄 앞 절 번호를 자연스럽게 처리(예: "이십오 절" 대신 생략하거나 짧게)해도 됩니다. 화면 원문은 절대 수정하지 않습니다.
- 음질은 UI로 노출하지 않고 내부에서 프리미엄 우선으로 처리하며, 성우 대체·음질 등급에 대한 안내 문구나 알림을 화면에 표시하지 않습니다.

**전달·연계**: 생성 후 파일 경로를 안내하고 "이 파일을 열어 ④ 듣기 청취와 ② 밑줄 긋기를 하신 뒤, 밑줄 친 단어·문장을 알려 주십시오"라고 네 번 읽기 과제로 이어 줍니다. 밑줄 결과는 렌즈 질문(특히 배경·주된 감성)의 출발점으로 씁니다.

## 리서치 브리프

`tnt-research-agent`에게 전달할 항목입니다. 설교자가 스스로 얻기 어려운 자료만 다룹니다. 관찰(본문에서 무엇이 보이는가)은 리서치 범위가 아닙니다.

1. **지리·시대 배경**: 사건 장소의 지리적 성격(교통·상업·정치적 위치), 시대 상황. 예: 마가복음 5장이라면 갈릴리 호수 주변 동선과 군중 상황.
2. **사회·종교 제도**: 본문 이해에 필요한 율법·관습·정결 규정. 예: 혈루증이 부정으로 간주된 근거(레 15:25-27)와 접촉 시 부정 전이 관념, 그로 인한 사회적 배제.
3. **원어 관찰 재료**: 반복되는 단어, 강조 어순, 시제 변화, 호칭의 원어적 뉘앙스(예: "딸아"의 무게). 해석 결론이 아니라 관찰을 돕는 사실 위주로.
4. **문맥 지도**: 앞뒤 단락 요약과 저자의 배열 의도에 관한 사실 정보. 예: 야이로 사건(막 5:21-24, 35-43) 사이에 여인 사건이 삽입된 샌드위치 구조.
5. **등장인물 신분 정보**: 호칭·직분·사회적 위치에 관한 배경 사실(성격 해석은 제외).
6. 금지: 다섯 렌즈 관찰 문장 초안, 주된 감성 한 문장, 신학적 메시지 요약문을 만들어 주는 것.

## 소크라테스 질문 뱅크

렌즈별 관찰→해석 사다리로 배열했습니다. 코치가 인라인 질문 시 사용합니다. 여기서 1~2개씩 골라 설교자의 답에 맞게 조율합니다. 예시는 모두 혈루증 여인 이야기(막 5:25-34) 기준입니다.

**배경(Setting)** — 이야기가 깔리는 바닥
1. 이 사건은 어디에서, 어떤 시간·상황에서 일어납니까? 평상시입니까, 위기입니까, 이동 중입니까? (예: 야이로의 딸을 살리러 급히 가는 길, 군중이 밀치는 좁은 거리 — 막 5:24)
2. 이 장면의 사회적·종교적 분위기는 어떠합니까? 금지, 부정, 배제 같은 압력이 보입니까? (예: 혈루는 부정 — 여인이 군중을 만지는 행위 자체가 금지선을 넘는 일)
3. 앞뒤 문맥은 어떻게 흘러갑니까? 이 사건이 하필 이 자리에 놓인 이유가 보입니까? (예: 두 절박함 — 야이로와 여인 — 이 교차하는 배열)

**인물(Character)** — 이야기 속을 몸으로 살아내는 사람
4. 주요 인물은 누구이며, 각 인물의 현재 상태는 어떠합니까? 육체·마음·관계·경제·신앙의 다섯 면으로 보십시오. (예: 12년 출혈, 재산 탕진, 배제와 고립, 그러나 "옷에만 손을 대어도"라는 믿음 — 막 5:25-28)
5. 이 인물은 이야기 속에서 어떻게 변합니까? 처음의 모습과 마지막의 모습을 나란히 놓아 보십시오. (예: 숨어서 손 뻗는 사람 → 떨며 고백하는 사람 → "딸"로 불리며 평안히 떠나는 사람)
6. 조연과 군중은 어떤 역할을 합니까? 장벽입니까, 무대입니까, 증인입니까? (예: 군중은 여인에게 물리적 장벽이자, 회복 선언이 공개되는 무대)

**플롯(Plot)** — 문제·긴장·전환·해결의 길
7. 어떤 문제에서 이야기가 시작됩니까? 무엇이 막혀 있습니까? (예: 12년 질병, 악화, 경제 파탄 — 모든 길이 막힌 절망의 자리)
8. 긴장이 점점 커지는 장면은 어디입니까? 어느 순간 가장 조마조마합니까? (예: "누가 내 옷에 손을 대었느냐" — 노출의 긴장이 최고조로 상승, 막 5:30-32)
9. 전환점(Turning Point)은 어느 구절이며, 이야기는 어떻게 해결됩니까? (예: 손을 대니 혈루 근원이 마름(29절)이 사건의 전환, "딸아 … 평안히 가라"(34절)가 관계적 해결)

**주된 감성(Main Emotion)** — 이야기의 온도
10. 이 이야기는 어떤 감정으로 시작하고, 감정이 가장 높아지는 지점은 어디입니까? (예: 수치와 고립로 시작, 드러남의 공포에서 정점)
11. 감정의 방향이 뒤집히는 전환점은 어디이며, 마지막에 남는 여운은 무엇입니까? (예: "딸아"라는 부르심에서 두려움이 평안으로 뒤집힘)
12. 이 감정의 흐름을 한 문장으로 요약할 수 있습니까? 감정을 더 넣는 것이 아니라, 본문이 이미 흘려보내는 감정에 정직한 문장입니까? (예: "숨겨진 수치가 떨리는 고백을 지나 딸이라 불리는 평안으로 뒤집히는 이야기")

**신학적 메시지(Theological Message)** — 이야기의 심장
13. 이 사건을 통해 하나님(예수님/성령님)은 어떤 분으로 나타나십니까? 성품이 무엇으로 드러납니까? (예: 부정과 배제의 경계를 넘어 한 사람을 찾아 세우고 "딸아"로 호명해 관계와 정체성을 새롭게 하시는 분)
14. 인간은 어떤 존재로 그려지며, 복음의 어떤 측면(은혜·심판·부르심·회복)이 드러납니까? (예: 다 소진된 존재, 그러나 믿음은 감정이 아니라 예수님을 향해 손을 내미는 방향과 행동)
15. 이 모든 관찰을 한 문장으로 요약할 수 있습니까? 이 문장이 4단계에서 중심 메시지로 압축될 토대가 됩니다.

## 평가 루브릭

코치가 인라인 판정 시 사용합니다. 판정은 충분함 / 거의 됨 / 다시 생각 세 가지이며, 설교자의 문장을 재작성하지 않습니다.

| 렌즈 | 충분함 기준 | 다시 생각 신호 |
|---|---|---|
| 배경 | 장소·시간·상황 + 사회/종교적 분위기 + 앞뒤 문맥, 세 층이 모두 구절 근거와 함께 있음 | 지명만 나열, 분위기의 압력이 없음, 문맥 미확인 |
| 인물 | 주요 인물의 상태(육체·마음·관계·경제·신앙 중 3면 이상)와 변화(처음→끝)가 기록됨 | 이름만 적고 끝냄, 변화가 없음, 상상으로 성격 창작 |
| 플롯 | 문제→긴장→전환점(구절 특정)→해결의 네 지점이 모두 구절과 연결됨 | 줄거리 요약에 그침, 전환점 구절을 못 짚음 |
| 주된 감성 | 감정의 곡선(시작→정점→전환→여운)이 보이고 한 문장 요약이 있음 | 감정 단어 하나로 끝냄("은혜롭다"), 본문에 없는 감정을 주입함 |
| 신학적 메시지 | 하나님이 어떤 분으로 나타나시는지 + 인간의 모습 + 복음의 측면이 있고 한 문장 요약이 있음 | 교훈("우리도 믿음을 갖자")으로 건너뜀, 하나님이 주어가 아님 |

**흔한 오답 패턴과 조언 포인트**
- **해석을 서두름**: 관찰 질문에 적용·교훈으로 답함. → "그 결론은 잠시 접어 두시고, 본문 몇 절에서 무엇이 보이는지 먼저 말씀해 주십시오."
- **감성 렌즈 생략·축소**: "맞는 말인데 내 이야기 같지 않은" 설교의 원인. → "인물의 행동은 늘 감정의 열매입니다. 여인은 왜 숨어서 손을 뻗었을까요?"
- **정보 나열**: 관찰이 주해 사전 요약처럼 됨. → "그 정보가 이 장면의 공기를 어떻게 바꿉니까?"
- **본문에 없는 것 창작**: 상상으로 세부를 지어냄. → "그 관찰의 근거 구절은 어디입니까?" 3단계(재현)의 상상과 2단계의 관찰을 구분해 줍니다.
- **다섯 렌즈를 따로 놂**: 렌즈들이 맞물리지 않음. → "감성의 전환점과 플롯의 전환점이 같은 구절입니까, 다른 구절입니까?"

## 흔한 함정과 코칭 포인트

1. **한두 번 읽고 노트부터 채우려 함** — 반복이 곧 관찰의 문입니다. 세 번쯤 읽어야 본문이 입체가 되고, 다섯 번 이후에야 "하나님은 여기서 무엇을 하시는가"가 보이기 시작합니다. 읽기 횟수를 먼저 확인하십시오.
2. **배경을 무대 정보로만 취급함** — 배경은 단순한 무대가 아니라 "이야기가 일어날 수밖에 없는 분위기의 압력"입니다. 장소·시간을 적었다면 반드시 분위기와 문맥까지 묻습니다.
3. **관찰 단계에서 설교 개요를 짜기 시작함** — "이걸로 3대지가 나오겠다"는 반응이 나오면 멈춥니다. 2단계는 도면을 보는 단계이지 집을 짓는 단계가 아닙니다.
4. **신학적 메시지가 교훈문이 됨** — "우리도 ~하자"는 이 단계의 답이 아닙니다. 앞의 네 렌즈가 이야기의 몸이라면 신학적 메시지는 심장입니다. 하나님이 주어인 문장으로 다시 묻습니다.
5. **리서치 자료를 관찰로 착각함** — 배경 지식이 많아져도 본문을 직접 본 것은 아닙니다. "그 자료가 본문의 어느 구절과 만납니까?"로 본문으로 되돌립니다.
