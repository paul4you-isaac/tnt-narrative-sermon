# T&T 내러티브 설교 코칭 시스템 (Claude Code 플러그인)

임도균 「스토리가 살아있는 설교」(Text-story driven Preaching)에 근거한 **10단계 내러티브 설교 코칭** Claude Code 플러그인입니다.

> **핵심 원칙 — 대필하지 않는다.**
> 이 플러그인은 설교를 대신 써 주는 도구가 아닙니다. 스토리텔링·중심 메시지·초안·적용·기도문은 **설교자가 직접 씁니다.** 코치(Claude)는 질문·리서치·판정 기준·분량 안내·프롬프터 생성으로 그 과정을 돕습니다.

## 구성

### 오케스트레이터
- **tnt-sermon-coach** — 전체 10단계를 진행하는 인라인 코치 + 진행 관리. "T&T 코칭 시작 [본문]"으로 시작합니다.

### 10단계 스킬
| 단계 | 스킬 | 내용 |
|---|---|---|
| 1 | tnt-step01-select | 본문을 선별하라 — 설교 단위(Text) 경계 확정, 5역본 비교 뷰어(구문 배열) 생성 |
| 2 | tnt-step02-read | 본문을 정독하라 — 다섯 렌즈(배경·인물·플롯·감성·신학) 관찰 |
| 3 | tnt-step03-retell | 본문을 재현하라 — 목격자 시점 스토리텔링 원자료(구술 우선) |
| 4 | tnt-step04-compress | 본문을 압축하라 — 한 문장 중심 메시지 |
| 5 | tnt-step05-connect | 청중과 연결하라 — 오늘의 접점 |
| 6 | tnt-step06-path | 길을 선택하라 — 설교 모델(단순형/대화형/대지형) 선택 |
| 7 | tnt-step07-draft | 초안을 작성하라 — 7블록 프롬프터 초안 |
| 8 | tnt-step08-polish | 초안을 고도화하라 — 리듬·밀도·루브릭 보강 |
| 9 | tnt-step09-resolve | 공감과 결단으로 마무리하라 — 조립·검수·프롬프터 |
| 10 | tnt-step10-deliver | 전달하라 — 최종 낭독 프롬프터 |

## 설계 원칙

- **한 번에 한 단계**, 게이트 판정 없이 통과하지 않습니다.
- **성경 텍스트는 코치가 생성하지 않습니다** — 판권·정확성 문제로 사용자가 붙여넣습니다.
- **특정 성도를 알아볼 수 있는 예화는 반드시 익명화**합니다.
- **맞춤법 교정**은 설교자 자신의 문장에만 적용하고, 성경 인용은 교정하지 않습니다.
